Hotel Reservation System
Project Description
 The Hotel Reservation System is a Python-based application designed to manage hotel rooms and reservations efficiently.
Features
.Display all hotel rooms
.Search rooms by type and AC availability
.Book a room
.Cancel a booking
.View available and booked rooms
.View rooms floor-wise
.Manage Normal and VIP customers
.Calculate the total booking bill
.Provide a 10% discount for VIP customers
.Save hotel data in JSON format
Technologies Used
.Python
.Object-Oriented Programming (OOP)
.JSON
.File Handling
.Exception Handling
.Date and Time
How to Run
1.Download or clone the project.
2.Open the Python file.
3.Run the program.
4.Select an option from the main menu.
Project Outcome
The system provides a simple and efficient way to manage hotel room availability, customer bookings, cancellations, and billing.
